# KDD Customer Segmentation

This project applies the Knowledge Discovery in Databases (KDD) process to segment customers using K-Means clustering.

## Dataset

[Customer Personality Analysis Dataset](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis)

## Final Result

The final K-Means model selected two customer segments:

- Cluster 0: Lower-value customer segment
- Cluster 1: Higher-value customer segment

The model and supporting artifacts are included in this project.
